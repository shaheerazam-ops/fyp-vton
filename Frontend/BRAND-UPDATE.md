# FitLayer widget brand update

Visual direction based on the user's FitLayer homepage screenshot: charcoal (#1D1D1B), terracotta (#B06E52), ivory (#F6F3EF), stone (#DAD6CF), DM Serif Display headings, DM Sans UI.

## Run

Open a terminal in `D:\FYP\Widget\Backend`:

```powershell
.\.venv\Scripts\Activate.ps1
python -m uvicorn api.local_demo:app --reload --port 8000
```

In a separate terminal, from `D:\FYP\Widget\Frontend`:

```powershell
npm install
npm run dev
```

Visit `http://127.0.0.1:5173`. Press **Try it on virtually**, upload a person photograph (or use the sample), and generate a preview. The chosen demo garment is preloaded, but the *Testing options* section lets you upload another garment image. Vite forwards `/api/v1/try-on` to `http://127.0.0.1:8000/v1/try-on`.

This is a local CPU demo; images are blended, not generated by full IDM-VTON. The storefront is a demonstration of how the modal might appear on a retailer site; a self-contained third-party JavaScript SDK is a separate integration step.

To update an existing frontend, replace `src/App.jsx`, `src/style.css` and optionally `public/` from this ZIP. Keep your other files if you have local modifications, after backing them up. Don't copy `node_modules` or your Python `.venv`.

Build validation was not completed here because `npm install` did not finish within the available runtime.
